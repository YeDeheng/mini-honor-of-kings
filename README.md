# 王者峡谷 · 极简版 (Mini Honor of Kings)

一个**零依赖、纯原生 HTML5 Canvas + JavaScript** 编写的极简俯视角 MOBA 网页小游戏，还原《王者荣耀》的核心对战体验——直接用浏览器打开即可游玩，支持部署到 GitHub Pages。

## 核心特性

- **三种对战模式**：
  - **1v1 墨家机关道**：单路对决（1 防御塔 + 1 水晶 + 河道之灵）
  - **3v3 精简峡谷（推荐）**：双防御塔中路推进 + 红蓝 Buff + 暴君小龙 + 草丛视野
  - **5v5 经典三路**：上中下三路完整兵线、多塔推线与团队团战
- **四位特色英雄（各含被动 + 3 个主动技能）**：
  - 🛡️ **圣骑之力 · 亚瑟**（战士/坦克）：圣光守护、誓约之盾、回旋打击、圣剑裁决
  - 🔥 **暗夜萝莉 · 安琪拉**（法师/爆发）：咒术火焰、火球术（5 连火球）、混沌火种、炽热光辉
  - 🏹 **半神之弓 · 后羿**（射手/持续输出）：惩戒射击、多重箭矢、落日余晖、灼日之矢
  - 🗡️ **青莲剑仙 · 李白**（刺客/机动收割）：侠客行、将进酒（三段回影）、神来之笔、青莲剑歌
- **完整 MOBA 机制**：
  - 兵线定时刷新推进（含每 3 波炮车）、补刀与经验金币共享
  - 防御塔射程警示（接近显黄圈、锁定显红圈）、无兵线减伤保护、攻击敌方英雄自动拉仇恨
  - 草丛隐身视野机制、红/蓝 Buff 与全队增益暴君
  - 10 件经典装备商店、左侧快捷出装、装备出售
  - 召唤师技能（治疗术、闪现、回城）、一血/双杀/三杀/团灭语音级播报与 Web Audio 合成音效
  - 智能 AI 队友与对手（自动对线、拉扯走位、躲塔、残血撤退、出装与连招）
- **移动端原生触控 & PWA 全屏体验**：
  - 自动识别触屏设备，启用左手浮动虚拟摇杆 + 右手经典王者弧形技能轮盘（支持真正的多指同时操作）
  - 技能支持**点按智能锁敌**或**按住拖动实时瞄准释放**，闪现默认沿摇杆/面朝方向瞬移
  - 移动端自适应相机缩放、全屏按钮与 PWA Web App 清单（支持“添加到主屏幕”横屏全屏游玩）

## 操作说明

> ⌨️ **电脑端支持纯键盘零鼠标 / 键鼠混合操作**；📱 **手机/平板端自动启用左手虚拟摇杆 + 右手技能轮盘多点触控**。

### 手机 / 平板触控操作

| 触控区域 / 手势 | 功能 |
| :--- | :--- |
| 左下角虚拟摇杆 | 浮动摇杆 360° 流畅走位（支持与右手普攻/技能同时操作） |
| 右下角 `普攻` 按钮 | 按住持续普通攻击，自动锁定最近/低血目标 |
| 右下角 `1/2/大招` 按钮 | **轻点**：智能锁敌释放；**按住拖动**：实时显示范围与方向/落点指示器，松手精准施法 |
| `闪现` / `治疗` / `回城` | 一键释放召唤师技能（闪现沿当前移动/朝向瞬移） |
| 点击 / 拖动小地图 | 自由拖动查看各路视野，点 `🎯` 按钮重新锁定英雄 |
| 点击顶部比分栏 / 金币栏 | 打开战绩面板 / 装备商店；点击 `⛶` 切换全屏模式 |

### 桌面端键盘 / 鼠标操作

| 按键 / 操作 | 功能 |
| :--- | :--- |
| `WASD` / `方向键` | 移动走位（纯键盘流畅走 A；也支持鼠标右键移动） |
| `J` / `空格`（`Space`） | 普通攻击（按住持续攻击，自动锁定最近/低血目标；也支持鼠标左键） |
| `U` / `I` / `O`（或 `Q` / `E` / `R`、`1` / `2` / `3`） | 释放一技能 / 二技能 / 大招（纯键盘智能锁定敌方英雄，移动鼠标则朝鼠标施法） |
| `K`（或 `H`） | 治疗术（回复附近友军生命并短暂加速） |
| `L`（或 `F`） | 闪现（纯键盘朝面朝方向瞬移；移动鼠标时朝鼠标方向瞬移） |
| `B` | 回城（引导 3 秒传送回泉水） |
| `G` | 一键购买顶部推荐装备（无需打开商店） |
| `P` | 打开 / 关闭装备商店 |
| `Tab` | 按住查看全场战绩面板 |
| `Y` | 锁定 / 解锁英雄视角（也可点击小地图观察全图） |
| `M` / `Esc` | 静音开关 / 暂停菜单 |
| 选人界面 `←` `→` / `Enter` | 切换英雄 / 直接开始对战 |

## 本地运行

项目零外部依赖、无需构建：

1. 直接双击根目录下的 `index.html` 用浏览器打开；
2. 或者启动任意本地静态服务器：
   ```bash
   python3 -m http.server 8080
   ```
   然后访问 `http://localhost:8080`。

## 项目结构

```text
mini-honor-of-kings/
├── index.html          # 游戏入口与 HUD 界面
├── manifest.json       # PWA Web App 清单（移动端全屏横屏）
├── css/style.css       # 王者黑金风格 UI 与移动端自适应样式
├── js/
│   ├── config.js       # 全局常量、阵营与数学工具
│   ├── audio.js        # Web Audio API 合成音效模块
│   ├── items.js        # 装备库与智能快捷出装推荐
│   ├── heroes.js       # 四位英雄数值与技能定义
│   ├── map.js          # 1v1 / 3v3 / 5v5 峡谷地图生成
│   ├── ai.js           # AI 英雄战术行为树
│   ├── engine.js       # 60fps 核心战斗与物理引擎
│   ├── renderer.js     # HTML5 Canvas 场景、特效与小地图渲染
│   ├── ui.js           # HUD、商店、战绩与播报管理
│   └── main.js         # 输入处理与主循环入口
└── LICENSE             # MIT 开源协议
```
