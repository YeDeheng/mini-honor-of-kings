一款零依赖、纯原生 HTML5 Canvas + JavaScript 实现的极简俯视角 MOBA 网页游戏。打开浏览器即可直接开局，移动端自动启用左手浮动虚拟摇杆、右手拖动瞄准技能轮盘与 PWA 全屏横屏体验，电脑端既支持零鼠标纯键盘智能锁敌操作，也兼容键鼠混合操控。

## 在线试玩

直接点击访问：https://yedeheng.github.io/mini-honor-of-kings/

> 移动端建议横屏游玩，进入对局后点击左上角 `⛶` 可切换全屏；也可以通过浏览器菜单的「添加到主屏幕 / Add to Home Screen」以接近原生 App 的全屏体验启动。

## 核心特性

### 三种对战模式

- `1v1 墨家机关道`：单路正面 SOLO，1 座防御塔 + 1 座水晶 + 河道之灵，节奏紧凑。
- `3v3 精简峡谷（推荐）`：中路双防御塔推线，搭配上下野区红蓝 Buff、暴君与草丛视野。
- `5v5 经典三路`：上、中、下三路兵线与多塔推进，体验完整团队拉扯与团战。

### 完整 MOBA 机制

- 兵线与经济成长：各路定时刷新兵线（每 3 波附带炮车），支持补刀、经验金币共享与 1~15 级属性成长。
- 防御塔机制：接近塔范围显示黄色警示圈、被锁定转为红色警告，内置无兵线减伤保护及塔下攻击敌方英雄自动拉仇恨逻辑。
- 野区与视野：草丛隐身与视野暴露机制，击杀红/蓝 Buff 获取强化效果，拿下暴君为全队提供增益。
- 装备与快捷出装：内置 10 件经典装备（支持最多 6 格，已购装备可按原价 70% 出售），支持左侧推荐一键买装（按键 `G` 或直接点击）。
- 战局反馈与音效：纯 Web Audio API 实时合成打击、技能与击杀音效，提供右上角击杀播报、一血/双杀/三杀/团灭横幅与赛后 MVP 结算面板。
- 战术 AI 队友与对手：AI 英雄具备自动对线、补刀、拉扯走位、躲塔、残血撤退、动态出装与技能连招能力。

## 操作指南

### 手机 / 平板触控操作

进入对局后自动识别触屏并显示移动操控布局，支持真正的多指同时操作：

| 触控区域 / 手势 | 功能说明 |
| :--- | :--- |
| 左下半屏虚拟摇杆 | 浮动摇杆 360° 走位，可与右手普攻、技能同步操作 |
| 右下角金色 `普攻` 按钮 | 按住持续普攻，自动锁定附近或残血目标 |
| 右下角 1 / 2 / 大招按钮 | 轻点自动锁敌释放；按住并拖动可实时预览范围与方向/落点指示器，松手施法 |
| `回城` / `治疗` / `闪现` | 点击释放召唤师技能，闪现默认沿当前移动或朝向瞬移 |
| 顶部比分栏 / 金币栏 | 点击比分栏查看全场 KDA 战绩，点击金币栏打开装备商店 |
| 左上角小地图与工具栏 | 拖动小地图自由观察各路视野，点击 `🎯` 重新锁定英雄，点击 `⛶` 切换全屏 |

### 电脑端操作（支持纯键盘零鼠标）

纯键盘游玩时所有攻击与技能均自动智能锁敌；若移动鼠标，技能与闪现会自动切换为朝鼠标位置施法，同时也支持鼠标右键移动与左键攻击。

| 按键 / 操作 | 功能说明 |
| :--- | :--- |
| `WASD` / `方向键` | 移动走位（也支持鼠标右键点击移动） |
| `J` / `Space` | 普通攻击，按住持续锁敌输出（也支持鼠标左键） |
| `U` / `I` / `O`（或 `Q` / `E` / `R`、`1` / `2` / `3`） | 释放一技能 / 二技能 / 大招 |
| `K` / `H` | 治疗术，回复自身及附近友军生命并短暂加速 |
| `L` / `F` | 闪现，朝当前朝向或鼠标方向瞬移 |
| `B` | 回城，引导 3 秒传送回泉水（移动或受击打断） |
| `G` | 一键购买左侧首位推荐装备 |
| `P` | 打开 / 关闭装备商店 |
| `Tab` | 按住查看全场战绩面板 |
| `Y` | 锁定 / 解锁英雄视角（解锁后可拖动小地图查看全图） |
| `M` | 切换音效静音 |
| `Esc` | 关闭商店或打开暂停菜单 |
| 选人界面 `←` `→` / `Enter` | 切换英雄 / 直接开始对战 |

## 项目结构

```text
mini-honor-of-kings/
├── index.html          # 页面入口、选人界面与游戏内 HUD
├── manifest.json       # PWA 配置清单（支持移动端全屏横屏）
├── css/
│   └── style.css       # 黑金主题 UI 与移动端触控响应式样式
├── js/
│   ├── config.js       # 全局常量、模式配置、阵营与数学工具
│   ├── audio.js        # Web Audio API 合成音效模块
│   ├── items.js        # 10 件装备数据与快捷出装推荐
│   ├── heroes.js       # 四位英雄数值、被动与技能定义
│   ├── map.js          # 1v1 / 3v3 / 5v5 地图、塔、野怪与草丛生成
│   ├── ai.js           # AI 英雄对线、团战、出装与撤退逻辑
│   ├── engine.js       # 60fps 战斗结算、弹道、兵线与状态机引擎
│   ├── renderer.js     # HTML5 Canvas 场景、特效与小地图渲染
│   ├── ui.js           # HUD 刷新、商店、战绩面板与播报管理
│   └── main.js         # 键鼠与多点触控输入处理及主循环入口
├── LICENSE             # MIT 开源协议
└── README.md           # 项目说明文档
```

## 本地运行

项目无任何构建工具，无需安装依赖（不需要 `npm install`）：

1. 直接双击根目录下的 `index.html` 用现代浏览器打开即可游玩。
2. 或者在项目目录下启动任意本地静态服务：

```bash
python3 -m http.server 8080
```

随后在浏览器访问 `http://localhost:8080`。
